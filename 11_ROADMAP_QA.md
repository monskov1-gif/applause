# PRODUCTION ROADMAP AND QA

## Этапы

0.  Аудит, сравнение движков, проверка Pages, риски и архитектура. 1.
    Прототип одной комнаты: 2.5D-персонаж, камера, коллизии, интеракция,
    диалог, маска, свет, сохранение, Pages. 2. Vertical slice от
    пробуждения до первой аномалии/перехода. 3. Базовые системы: хаб,
    главы, маски, камера, фотоаппарат, редактор сценария, диалоги,
    флаги, сохранения, UI. 4. Производство глав по одной с интеграцией в
    хаб. 5. Финал: Алла Ева, гримёрка, коллапс, мюзикл, эпилог. 6.
    Релиз: Pages, браузеры, пути, сохранения, лицензии, оптимизация,
    credits.

## QA

- [ ] GitHub Pages запускает игру, включая repository subpath.
- [ ] Все ассеты загружаются с правильным регистром.
- [ ] Нет критических ошибок консоли.
- [ ] Обновление страницы сохраняет прогресс; повреждённое сохранение
  обрабатывается.
- [ ] Холодный запуск работает без кеша.
- [ ] Все главы и переходы проходимы.
- [ ] Выборы дают ожидаемые последствия.
- [ ] Друзья имеют агентность.
- [ ] Маски меняют восприятие пространства.
- [ ] Фотоаппарат используется в понятных загадках.
- [ ] Правки сценария не ломают флаги.
- [ ] Подсказки к твисту есть заранее и понятны при повторном
  прохождении.
- [ ] Кукольник не становится независимым злодеем; Алла Ева отвечает за
  поступки.
- [ ] Финал визуально раскрывает связь ролей; эпилог завершает дугу.
- [ ] Громкость настраивается, есть субтитры, режим уменьшения
  вспышек/тряски и облегчённая ритм-игра.
