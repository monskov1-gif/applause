# THE FINAL SHOW — Claude Code package

Полный пакет production-документов для браузерной 2.5D игры. Распакуй в
корень репозитория, добавь референсы в `references/` и музыку в
`audio/music_references/`, затем передай Claude Code файл
`00_MASTER_INSTRUCTIONS.md`. Сначала Claude должен провести аудит и
сравнить движки, а не сразу писать игру.

Файлы: `00_MASTER_INSTRUCTIONS.md`, `01_PROJECT_OVERVIEW.md`,
`02_STORY_BIBLE.md`, `03_CHARACTERS.md`, `04_FRIEND_STORY_ARCS.md`,
`05_GAMEPLAY.md`, `06_TECHNICAL_REQUIREMENTS.md`, `07_VISUAL_STYLE.md`,
`08_LEVEL_DESIGN.md`, `09_UI_UX.md`, `10_AUDIO.md`, `11_ROADMAP_QA.md`,
`12_REFERENCE_TEMPLATE.md`.
