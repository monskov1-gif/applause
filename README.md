# THE OTHER ME: APPLAUSE, PLEASE!

Театральная 2.5D story-driven adventure для браузера. Накануне 18-летия Варя просыпается в Театре имени М. Ковалевского. Ей нужно поставить спектакль, вернуть пропавших друзей из шести жанровых миров и понять, кто такая прима Алла Ева.

**Играть:** https://monskov1-gif.github.io/applause/ (лучше всего с компьютера и в наушниках)

## Что внутри

| Часть | Жанр | Ключевые механики |
|---|---|---|
| Акт I. Театр-хаб | закулисная сказка | исследование, три маски (Комедия / Трагедия / Драма), фотоаппарат, тень-мост от софита, диалоги и выборы |
| Полина: THE HOUSE THAT LAUGHS | хоррор-комедия | дождь и свет, прятки в шкафу, фото-аномалии, кодовый замок; в кульминации играешь за Полину |
| Рубен: THE LAST HEIST | неон-ограбление | доска плана (маршрут, гаджет, время), стелс против охраны, глушилка или голо-маска, лазеры по ритму, погоня |
| Матвей: 100 STEPS TO THE INEVITABLE | школьная дорама | постановка «идеальных моментов» (зонт и тайминг, записка, кадр под аркой), финал — сто шагов назад |
| Эрика: THE CITY NEVER SLEEPS | нуар 1940-х | свидетели, улики (одна видна только в маске Трагедии), доска расследования с противоречиями |
| Лиза: THE TOWER IS NOT A HOME | книжная сказка | волосы как верёвка, лассо, мост и лифт-противовес; Лиза уходит сама, принц опаздывает |
| Ангелина: DEBUT | K-pop | танцевальная связка, вокальная ритм-сцена, выбор образа, живой микшерный пульт, дебют |
| Акты III–IV | детектив в театре | архив, кабинет худрука, записки Кукольника, зеркало, сверка показаний |
| Акты V–VII | гримёрка → обрушение → мюзикл | разговор с Аллой Евой; коридор, где жанры накладываются друг на друга; THE QUEEN'S LAST CURTAIN (зеркальная хореография, раскрытие, поклоны); эпилог-день рождения |

Ещё в игре: блокнот режиссёра (персонажи, места, предметы, улики, сценарий), фотоархив, история реплик, ускорение и пропуск прочитанного, четыре слота сохранений (IndexedDB) с экспортом и импортом, автосохранение, пауза в любой сцене, настройки громкости (музыка / эффекты / голоса), масштаб интерфейса, качество графики, режим «меньше вспышек», «без тряски», повышенный контраст, облегчённые ритм-сцены, калибровка задержки звука, экспериментальное сенсорное управление.

## Управление

WASD или стрелки — ходить, Shift — быстрее, E / Enter / Пробел — действие, 1 / 2 / 3 — маски, Q — снять маску, C — фотоаппарат, Tab — блокнот, H — история реплик, Ctrl — пропуск прочитанного, Esc — пауза. Ритм-сцены: D F J K или стрелки.

## Движок и архитектура

Выбран web-native стек: **TypeScript + Three.js + Vite**. Сравнение вариантов:

| Критерий | Godot 4 (Web) | Unity WebGL | Unreal 5 | TS + Three.js |
|---|---|---|---|---|
| Статический GitHub Pages | да, но Godot 4 с потоками требует COOP/COEP, которых Pages не отдаёт; без потоков возможны проблемы со звуком | да, нужны настройки сжатия и MIME | нет: веб-экспорта в UE5 нет, Pixel Streaming требует сервера | да, обычные статические файлы |
| Размер первой загрузки | ~30–40 МБ движка | ~15–40 МБ | — | ~0,8 МБ (главы грузятся по требованию) |
| 2D-спрайты в 3D, свет, bloom | отлично | отлично | — | отлично (WebGL2, постобработка) |
| Мобильные браузеры | средне | слабо (память) | — | хорошо |
| Стоимость | редактор есть | редактор есть | — | системы пишутся своими руками |

Цена своего стека — сцены, диалоги и катсцены приходится писать самому. Это сделано данными и небольшими модулями.

```
web/index.html         точка входа для разработки
src/core/              состояние, версионированные сохранения, ввод, синтезатор и секвенсор музыки
src/world/             комнаты-диорамы, акторы, коллизии, камера, маски, фотоаппарат, исполнитель диалогов
src/gfx/               рендер (низкое разрешение, bloom, цветокоррекция), процедурные текстуры, спрайты, портреты
src/ui/                интерфейс, меню, блокнот, сохранения, настройки, мини-игры, логотип (SVG)
src/data/              персонажи, блокнот, все реплики (src/data/dialogue/*.ts)
src/chapters/          хаб и главы — отдельные модули, грузятся лениво
tests/playthrough.mjs  полное автоматическое прохождение игры + проверка сохранений
```

Вся графика (спрайты, портреты, текстуры) и вся музыка создаются кодом: в сборке нет чужих изображений и аудио. Референсы из `references/` использованы только как ориентир.

## Разработка

```bash
npm install
```

```bash
npm run dev
```

```bash
npm run build
```

`npm run build` собирает игру прямо в корень репозитория (`index.html`, `assets/`, `fonts/`): GitHub Pages публикует ветку `main` из корня. Файл `.nojekyll` отключает Jekyll.

```bash
node tests/playthrough.mjs http://localhost:5173/
```

## Важно: лицензии шрифтов

Шрифты Aurelia Diamond, Cintarini и Highcrest (логотип), а также Lombardina Initial One (буквицы в письмах) распространяются по лицензиям «только для личного некоммерческого использования». Для подарочного некоммерческого проекта это допустимо. Для коммерческого — нужна покупка лицензий или замена шрифтов. Интерфейс набран открытыми шрифтами (SIL OFL): Playfair Display, Lora, Marck Script, Pixelify Sans.

Документация проекта лежит в `docs/`, референсы — в `references/`, архивы шрифтов — в `fonts-src/`.
